## 新环境应重新执行

1. 按 `README.md` 恢复依赖，运行应用和前端测试/构建。
2. 在目标 Mac 运行原生沙箱正负检查；重新核对实际部署的版本、进程、路径和出站限制。
3. 用自己的已入库真实数据完成网页运行、地图、下载和独立数值比较。
4. 数据同步、OIDC、对象权限、网络隔离、依赖安全扫描和生产恢复仍需对应范围验收。

目前没有整个官方 GEE API 的数值等价结论，也没有完整生产安全通过结论。上游/第三方遗留风险继续如实记录；历史容器扫描不能证明当前 Homebrew/原生依赖安全。

## GEE 兼容第三轮

本轮新增有限集合质量合成、逐景日期/属性 map、三个 UTC 日期方法、受限 Number 位运算，以及独立 Scala SPI 的实际 Float64/Float32 转换。具体参数限制见兼容矩阵；年/月平均长度、日历 fraction 与 ISO 周、质量平分等本地策略均没有 Google 数值对照，调用时给出说明。

- 应用测试：278 passed、1 skipped；默认跳过需要完整原生科学引擎的独立 SPI 测试。该 SPI 测试已另行启用并实际通过，验证真实 tile、NoData、band metadata 和物理类型。工具受限环境不允许嵌套 Seatbelt 时，四项原生隔离测试曾因系统拒绝失败；在允许运行 `sandbox-exec` 的环境复跑完整套件通过，未修改应用沙箱。
- 数值回归：原有 23 项多景输出、6 项质量合成输出、逐景毫秒日期参与计算均通过独立 NumPy/Rasterio 对照；两个单独 GeoTIFF 导出分别核对 Float64 和 Float32 类型。
- Edge 实际运行新增示例，完成地图、手动启动导出及浏览器下载。单景真实 Sentinel-2 NDVI 共 45,590 个有效像元，掩膜差异 0、最大绝对误差 `1.2851604658248306e-7`，低于 `1e-6` 容差；下载 SHA 与正式任务结果一致。该例只有一景，多景获胜选择另外由合成夹具验证。
- 前端 10 项测试及严格 TypeScript/生产构建通过。全量固定签名报告可在无数据/无原始审计目录的干净克隆中重复生成，不推导全 API 兼容百分比。
- 复查修正了质量缺测时 payload 掩膜、cast 后逐景元数据路由、临时词法作用域缓存，以及共享表达式扫描/替换的重复展开；图节点与运行资源预算保持有效。

原始失败尝试和更正说明保留在本机；可再生成的合成输入、扫描缓存和重复测试构建已清理。机器可读的本轮脱敏结果见 [兼容验证摘要](../reports/gee-compat-wave3.json)。
