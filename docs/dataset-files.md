# 数据集与文件管理

入口：`http://localhost:8787/?view=admin` → 数据集 → **文件**。管理员与数据管理员可以使用；研究员不能调用文件管理 API。已发布目录中的分析资产仍按当前工作区共享策略供计算使用，尚未引入逐项目 ACL。

## 使用

1. **添加数据集**创建草稿，填写名称、说明与许可证；已有目录可以直接打开文件面板。
2. **选择文件**或拖入文件。文件名不作为服务器路径；文件由 UUID 管理。支持 GeoTIFF、NetCDF、CSV、GeoJSON、JSON，单文件最多 512 MiB。
3. 浏览器在独立 Worker 中分块计算 SHA-256，再以 512 KiB 分块上传。暂停或服务重启后重新选择同一文件，按校验值恢复进度；相同数据集内同内容复用原上传记录。服务器核对完整长度和 SHA-256 后才显示“已存储”。
4. **下载原件**返回上传字节，保留原文件名。上传未完成时不能下载。JSON/CSV 均以附件下载，不在网页内执行或解析其内容。
5. GeoTIFF 可点 **配置入库**。明确填写 UTC 观测时间与物理单位；波段名按文件顺序填写，或读取文件描述。无描述时使用 `band_1` 等明确占位名称。单位不由系统猜测。
6. 入库任务在独立 Seatbelt 沙箱进程中校验、应用原始 scale/offset、保留掩膜并生成 float32 COG。每波段的量化误差、有效像素数、原始 dtype 与处理参数写入 STAC Item 的 `gee:processing`。
7. 入库成功后，**已入库影像资产**可下载各波段 COG。数据集仍保持原发布状态；新草稿必须在“管理”表单中主动发布，才可从工作台、openEO 与 GEE 适配接口选择。

NetCDF、CSV、GeoJSON 和 JSON 当前支持文件存储与下载，尚未提供通用的计算入库转换。同步供应方的原有 COG 及保留旧版本也列在资产列表中，可由管理员下载；不会把旧的歧义 Sentinel-2 数据重新激活。

## 处理边界

- API 仅向独立上传目录写入字节，其余数据目录在 Seatbelt 中只读；不在 HTTP 进程解析上传栅格。脚本进程不能读取暂存文件或 DB 凭据。
- GeoTIFF 入库只允许 `GTiff` 输入驱动。执行进程采用 deny-default Seatbelt，无网络，只开放一个只读原文件、运行库及自己的输出/临时目录；RSS 监督上限 2 GiB，墙钟时间 180 秒，并有 CPU 时间、文件大小、文件描述符和进程数 rlimit。此监督不等于容器或 cgroups 的硬资源限额。
- 当前入库上限：32 波段、单波段 400 万像素、全部波段共 6400 万像素、标准化输出合计 512 MiB。跨日期变更线的包围盒或缺少 CRS 等情况明确失败。大景自动切片仍待实现。
- 新文件进入已有数据集时，波段名称、顺序与单位必须一致。不会用通用管理表单修改已有数据的缩放、掩膜或坐标系。
- 暂存声明大小总配额为 8 GiB，最多 2048 文件、每数据集 500 文件；每用户最多 2 个未完成上传。队列最多 20 个入库任务、每用户 5 个，单个入库任务运行。完整用户磁盘硬配额和自动清理策略仍待生产实施。
- 每块写入后 fsync，数据库保存已提交偏移；重试时只截去未提交的尾部。完整文件在校验后原子改名。校验失败不会进入“已存储”或科学目录。
- 创建、完成上传、请求入库、入库成功和管理下载请求写入本地审计。下载审计代表请求已通过鉴权，不等于客户端已完整接收全部字节。
- 不提供无条件覆盖已有影像或物理删除功能；现有任务快照和结果继续保留。归档、保留期、引用检查与空间回收需独立实现后开放。

## 模块

| 模块 | 职责 |
| --- | --- |
| `web/src/admin/FileManager.tsx`、`fileHash.worker.ts` | 文件列表、选择/拖入、校验、续传、元数据与下载 |
| `gee/api/dataset_files.py` | 管理权限、分块 HTTP、附件下载与记录查询 |
| `gee/services/dataset_files.py` | 文件身份、配额、字节校验、状态与入库请求 |
| `gee/raster_ingest_runner.py` | 无凭据隔离栅格校验与 COG 标准化 |
| `gee/services/local_ingest.py` | 受控结果验证、资产发布、STAC、来源及审计 |
| `gee/worker.py` | 持久队列、执行隔离、超时与重启恢复 |

`data/uploads/` 与数据库一起纳入备份。迁移版本 3 增加文件状态表；不会删除旧账号、脚本、结果和 Items。生产部署仍需完成 Keycloak OIDC、TLS、有限数据库角色及完整依赖和出站验收，不能将本页功能验收等同于平台已具备全部上线条件。

当前 macOS 原生运行与验证边界见 [原生部署](native-macos.md)，实际 HTTP 上传 → 原生沙箱解析 → COG 发布/下载记录见 `audit/native-macos-live-v2/validation.json`。
