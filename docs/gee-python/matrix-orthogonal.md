# 逐像元紧凑 QR 与 SVD

本地固定形状 `RasterArrayImage` 支持 `Image.matrixQRDecomposition()` 和
`Image.matrixSingularValueDecomposition()`。两个 API 都只接收 `image` 参数，并从
同一影像像元的连续行优先波段读取一个显式 `toFloat()` 或 `toDouble()` 的二维矩阵。
API 名称与官方 [QR 文档](https://developers.google.com/earth-engine/apidocs/ee-image-matrixqrdecomposition)
和 [SVD 文档](https://developers.google.com/earth-engine/apidocs/ee-image-matrixsingularvaluedecomposition)
相同。

输入行数和列数各为 1–8，输入单元总数不超过 64，规格使用原有六字段 v1 矩阵协议，
`rhs_cols` 固定为 0。输出形状采用明确的本地紧凑约定，令 `p=min(m,n)`：QR 返回
`Q(m,p)` 与 `R(p,n)`，满足 `A≈Q×R`；SVD 返回 `U(m,p)`、`S(p,p)` 和 `V(n,p)`，
满足 `A≈U×S×Vᵀ`。每个因子按行优先顺序串接在同一结果中。输入和所有因子的合计输出
分别不超过 64 个单元，适用于高矩阵和宽矩阵；形状合法并不保证后续所有组合均能通过预算。

官方文字说明了正交因子和分解关系，但没有定义矩形矩阵的因子尺寸或紧凑／完整形式。上面
描述的是本地固定政策，不能据此宣称输出形状与 Earth Engine 相同。独立测试参考使用
NumPy/LAPACK。不同库在 QR 符号、SVD 符号以及重奇异值
子空间的基选择上可能不同。验证应比较有限性、重建误差、`QᵀQ`／`UᵀU`／`VᵀV`、
非负且降序的奇异值，以及预期掩膜，而不比较具体基向量。

原生 QR 使用 `hypot` 求列范数，以 Householder 反射和精确十进制点积／更新避免直接平方
造成的上下溢。SVD 首先尝试固定的 Commons Math 3.6.1，并核对精确二进制输入的整数秩、
正交性、范数意义下的重建残差及 Gram 矩阵的全部有效谱系数；不能使用该库的近零阈值把
有效方向归为零。未通过校验时，尝试最多 32 轮、80 位十进制精度的单边 Jacobi 分解，
之后仍需通过相同校验。宽矩阵先转置再交换左右因子。真实零方向才规范为零。

原生数值与准入分开：按源指数／有效位数预充整数消元、Gram 校验、精确输出乘积和有界
迭代的成本，实际瓦片再次核对源包络。十进制有效位数和小数位范围也有限制；Jacobi 的
固定有效位数与迭代中增长的小数位范围分别处理，后者的绝对上限为 65,536；精确输出乘积
仍按输入／输出包络限制。这些都是明确执行的资源边界，不能证明
所有可表示分解都能完成，也不是 CPU 时间硬上界。上游 SVD 与整个任务仍需墙钟超时。
原生单瓦片工作上限为 1 亿，合计为 10 亿；较大的瓦片或极端动态范围可在数值计算前拒绝。

本轮普通 2×2 SVD 的准入估算为每像元 174,556，单瓦片最多 572 像元（正方形边长 23）；
3×2 为每像元 230,504，最多 433 像元（正方形边长 20）。这是固定样本的预算校准，
源值包络改变时成本也会改变，并非吞吐测量。当前 256×256 瓦片不能直接通过这些估算；
生产布局调整及完整 Spark 验收仍需另行完成。

源无关参考会把输入 Float64 值视为精确二进制有理数，独立计算矩阵秩，只把真实零空间
对应的尾部奇异值规范为零，不使用容差判秩。若 NumPy/LAPACK 把数学上为正的奇异值丢成零，
参考会报告无法提供分解，而不会伪造正值或借用生产数值核的因子。极端病态输入应分别验证
各实现的正交性、有限性与重建残差；不要求 NumPy 和本地求解器给出相同奇异值或基。

有限静态 `ee.Array` 的同名 QR／SVD 方法也采用上述矩形紧凑形状，仍由 NumPy/LAPACK
在预充工作量后计算。逐像元 `Image` 则进入独立原生内核；常量折叠不是原生执行的证据。
源无关 Image 常量的 SVD 先以精确整数消元求秩，把真实零方向规范为零；若数值库丢失
仍应为正的奇异值，编译明确拒绝。静态 Array 保留原有数值库策略，两条路径分别测试。

秩亏、零矩阵和重复奇异值均为允许输入。QR 仍返回具有正交列的紧凑 `Q` 和上梯形 `R`；
SVD 的 `S` 为对角矩阵，奇异值非负且降序。输入矩阵任一元素缺测时，该像元所有因子均为
NoData；有效源 Infinity 在数值核之前拒绝。显式 Float32 输入先按 Float32 舍入，之后调用
`toDouble()` 不会恢复被舍入的位。数值核返回 Float64 因子；既有数组类型边界再决定后续
计算的精度。有限输入也不保证每个因子都能以有限 Float64 表示，或所有像元都能完成：
极端动态范围可能触发数值后端的可表示范围限制，超预算组合会被编译器拒绝。

示例用 QR 因子重建输入、投影观测并由 `R` 与 `Qᵀb` 求最小二乘系数。矩形 3×2／2×3
SVD 的全重建和保留两个奇异值的重建均可编译，测试也逐像元检查它们与输入一致；这里
`p=2`，保留两值仍是完整重建，不是降秩近似。Float32 舍入后转 Double 的矩形 SVD 重建也
通过。每个 SVD 组合图中只有一个矩阵值生产者。3×3 SVD 的 U/S/V 因子可以编译并验证。
第五十九批减少重复标量 DAG 扫描后，从三个奇异值中选择两个的真实秩二组合也可编译：
固定合成流程为45,601工作量／347节点，11个有限像元的99个单元与独立 NumPy 秩二参考
最大绝对误差4.45e-16，另一个缺测像元的9个输出均为NoData。这是合成图验证，没有新增
原生／完整Spark验收。完整3×3重建仍触及50,000步工作预算；QR正规残差仍被500节点
预检拒绝。测试保留当前精确诊断，没有改用手写标量公式，也没有放宽预算。共享的
50,000步编译工作量、500节点和64单元限制不变；符合形状上限不表示任意组合都可运行。
