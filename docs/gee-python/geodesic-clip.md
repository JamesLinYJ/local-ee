# 球面多边形裁切

本批扩展已有 `Image.clip` 的默认球面多边形路径；没有新增官方算法名称。
官方 Python／JavaScript 客户端仍生成原有 EE 表达式，本地新增独立的像元覆盖权重生产者。
本合同区分本地数值规则、客户端语法和 Google 实测等价；后者尚无证据。

## 数据与计算

`clip(ee.Geometry.Polygon(...))` 默认保留大圆弧边，不把顶点连接成平面直线。
有限 `MultiPolygon` 使用同一路径，孔洞须有明确且有效的壳／洞拓扑。
科学值保留原精度和先前 Float32／Double 转换阶段；权重另存为 Float64。
有限科学值的权重采用真实栅格投影下，多边形与像元的交面积除以像元面积；
源 NoData 的权重为有效的0，源 Infinity 即使位于裁切区外也拒绝。
正权重不会乘入科学值，取样以零权重转 NoData，沿用已有缺测行规则。

原生组件读取实际 CRS、布局、空间键、时间键和瓦片尺寸。
输出区域／分辨率不能冒充输入网格证据；波段、重采样和空间条件的上游推送在生产者处阻断。
几何的大圆弧在实际像元坐标下细分，再进行平面多边形相交。
四分点、中点和四分之三点的投影弦偏差目标为 `1e-6` 像元，弧段最多0.25度。
这是固定的本地数值政策，**不是面积误差的严格证明**。
达到深度、线段或工作预算仍不能满足时明确拒绝，不退回像元中心判定。
不使用区域归约的8位权重规则来猜测 `clip` 的量化。
同经度经线和赤道沿用输入端点所定义的精确轴向关系，避免三角函数往返制造假覆盖；
不按小权重阈值抹零。其他曲线的精确接触和 Google 的覆盖量化仍未确认。

原有显式 `geodesic=False` 路径仍采用历史二值中心掩膜；它与此处小数覆盖权重分开列示。
本批不把该历史行为升级为完整的 GEE 平面裁切等价声明。

## 官方写法与下游

```python
image = ee.ImageCollection('COPERNICUS/S2_SR_HARMONIZED').first().select('B4')
roi = ee.Geometry.Polygon([[
    [116.1, 39.8], [116.3, 39.8], [116.3, 40.0], [116.1, 40.0]
]])
clipped = image.clip(roi)
weights = clipped.mask()
science_rows = clipped.multiply(2).sample(geometries=True)
```

上述数据集仍须已按本地目录合同入库；代码不是自动下载或全球目录可用性承诺。
`mask()` 读取普通数值权重影像；选择、改名和已审查的一元／标量运算保留独立权重。
带权科学值继续只能进入明确审查的消费者，不能通过去掉 carrier 冒充原值栅格输出。

精确的裁切后足迹仍有独立边界：原目录足迹只供内部扫描，内部保留待解足迹的裁切身份。
当前省略研究区的科学取样仅接通单波段，须能证明实际输出仍有裁切权重，且删除缺测行；
证明必须对应首幅影像保留的那一个裁切区域，不能借用另一幅影像或另一研究区的权重。
多波段、读取权重后取样或保留缺测行需要显式研究区，避免输出整个源范围的有效零。
未解决的公开足迹提取明确拒绝，零波段选择、表达式三元分支、集合归约／toBands／qualityMosaic 和 unmask 足迹合并不能抹除该状态。集合 geometry() 同样不能把内部源范围作为精确结果返回。传递这个标记不代表这些操作已支持带权像元计算。

## 限制与资源

- 输入限定 EPSG:4326、测地线边及有效的 evenOdd 壳／洞多边形。
- 真实栅格 CRS 限于 EPSG:4326、3857 和普通分区内的南北半球 UTM；UTM 经度距中央子午线最多3度，不包含挪威／斯瓦尔巴的例外分区。变换失败不猜测坐标。
- 日期线跨越、极区／大范围、空／退化几何、左手内部和不明确拓扑拒绝。
- 点、线、`LinearRing`、`clipToCollection`、重复裁切和已有独立小数掩膜的组合尚未接通。
- 带权区域归约、地图透明度及科学值栅格导出仍待逐项实现；权重数值影像不能充当这些验收。
- 保留原50000编译工作、96深度、500图节点限制；规格、几何、细分和实际瓦片工作另有预充上限。
- 边界预算按真实布局的闭合像元候选去重，乘实际时间键数；不按空间键重复放大。上限仍为67108864工作单位，边界扫描与去重各最多1000000项；这是资源代理而非执行时间保证。
- 原生弧长要求大于 `1e-14` 弧度，距对跖弧长大于 `1e-12` 弧度；这是数值准入边界，不能说这些输入在数学上都退化。
- 源网格／投影坐标的浮点间距须满足小于弦容差八分之一的精度界限；极细网格、极大偏移和近极区舍入到极点的情况明确拒绝。
- Python 桥严格校验规范 JSON；JVM 独立校验结构、字段顺序、Float64 数字类型和有限范围。JVM 可接受部分等值数字拼写，不声称两种语言的浮点序列化字节完全相同。

官方文档说明 `clip` 保留输入波段与元数据，并遮蔽区域外数据。
[Image.clip](https://developers.google.com/earth-engine/apidocs/ee-image-clip)
及[发布记录](https://developers.google.com/earth-engine/docs/server/release-notes#august_28_2017)
支持多边形边缘有部分掩膜，但不能证明这里的浮点权重与 Google 按位相同。
[区域归约权重](https://developers.google.com/earth-engine/guides/reducers_reduce_region#pixels-in-the-region)
属于另一合同；不可把其量化及 `min(mask, coverage)` 套到连续裁切组合。
